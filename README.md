# college-ticket-service — «Сервис заявок колледжа»

REST API на Python для приёма и обработки заявок студентов колледжа (неисправности, учебные и хозяйственные вопросы).

**Стек:** FastAPI · Pydantic v2 · SQLAlchemy 2 · Alembic · SQLite · pytest · PyJWT.
Приложение работает полностью локально и не обращается к внешним сетевым сервисам.

## Цель

Дать студентам единое место для подачи заявок, операторам — очередь заявок с понятными статусами, а администрации — контроль: кто, когда и что сделал с заявкой, и сводный отчёт о нагрузке.

## Роли

| Роль | Кто это | Что может |
|------|---------|-----------|
| **student** | студент колледжа (роль по умолчанию при регистрации) | создаёт заявки, видит только свои, комментирует их, закрывает решённую заявку |
| **operator** | сотрудник ИТ‑отдела, учебной части или хозчасти | видит назначенные ему и свободные новые заявки, берёт их в работу, меняет статус, комментирует |
| **admin** | администратор сервиса | управляет категориями и ролями пользователей, назначает операторов, видит все заявки, аудит и отчёт |

## Границы системы и ограничения

**Входит в систему:** регистрация и вход (JWT), профиль, категории (CRUD для admin), заявки с фильтрацией по роли, назначение оператора, статусы `new → in_progress → resolved → closed`, комментарии, журнал аудита, отчёт, `/health`, OpenAPI (`/docs`), WebSocket‑уведомления.

**Не входит (ограничения):**

* нет веб‑интерфейса — клиентом выступают Swagger UI, curl или сторонний фронтенд;
* нет отправки email/SMS и интеграций с внешними сервисами — только локальная работа;
* нет вложений (файлов) в заявках и восстановления пароля;
* одна локальная БД SQLite — сервис рассчитан на один экземпляр и нагрузку учебного заведения;
* пароли хранятся только как стойкий хэш (scrypt с солью), права проверяются на сервере для каждой операции.

## Создание окружения

Нужен Python **3.11+** (проверено на 3.13 и 3.14).

**Windows (PowerShell / cmd):**
```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

**Linux / macOS:**
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Запуск приложения одной командой (`python -m app`) и тесты (`python -m pytest`) появляются на этапе УП6.
